# 0.6.11 verification — 2026-10-24 (Asia/Shanghai)

- Fixed a concrete result-loss case: an incomplete or malformed SSR payload previously caused the Douyin browser decoder to throw before examining an already available current-player HTTPS URL. Normal player extraction now continues when state is unavailable. Explicit private/prohibited/DRM states remain terminal, including numeric private flags and alternate render blocks.
- The actual snapshot URL is checked against both the requested and native-callback work IDs, so a stale callback after SPA navigation cannot relabel another work. History callbacks update the page tracking and adopt a short link's first canonical work once. A later work cannot replace it. When currentSrc exists, other src/source declarations are no longer marked active. Visible Douyin extraction no longer re-adds unfiltered media after decoding.
- SearchFailure preserves a bounded, named diagnostic through inner Douyin parsing and outer four-provider aggregation, instead of remapping the entire report to one generic timeout/session message. Both all-failure dialogs and partial-result pages can copy diagnostics. Reports omit URLs, session headers and common credential fields, including quoted JSON fields. Normal non-aggregate errors keep their existing friendly mapping.
- All production Java compiled with JDK 17, Android 35 and the pinned engine dependencies. Relevant checks passed: Douyin search 29, existing Douyin/XHS photos 19, parallel providers 15, playback/page/session tracking 20, nested search diagnostics 22, XHS/error mapping 29, actual Douyin scanner JavaScript 10, actual general scanner JavaScript 12 (156 assertions). The changed navigation callbacks were verified by production compilation; no Android UI execution is claimed.
- No Android phone/emulator or failing user share URL is available. End-to-end Douyin search/download, website login/verification, three-site full availability, and the clipboard UI still require device verification. This release does not claim a successful live Douyin download or that the third-party sites are all working. No authentication/challenge bypass or media decryption was added.
