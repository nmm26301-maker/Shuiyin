# 0.6.9 verification — 2026-10-23

- Added an actual multipart TikTokio HTTP form adapter using the currently served index.js protocol (`page`, `ajax=1`). Local wire tests check headers, body, server errors and response classification. Live public TikTok and Douyin sample requests returned HTTP 200 JSON errors (`Wrong link format`), with no media. This is evidence of server-side rejection, not a successful download.
- Added the documented Cobalt API protocol for an explicitly configured authorized/self-hosted instance. API-Key headers are never forwarded on redirects; auth failures and split-track responses do not become successful media results. No working Cobalt credentials/instance are supplied or claimed.
- Website WebViews are attached to the Activity content window and removed/destroyed on completion. Normal HTTPS subframes are permitted. A progress action cancels the current search before opening a stable visible website for normal verification; retry reuses only this application's own cookies and User-Agent.
- Extended ordinary Douyin playback collection to extensionless public CDN/play requests, retaining signed queries and HTTP headers. The selected work page is checked so login/feed/other-work requests are excluded. Only the selected work's media state is exported; account data is not exported. No CAPTCHA, authorization or DRM bypass is implemented.
- New checks: 21 real local HTTP-wire/response checks, 17 playback/session/header checks and 5 executions of the actual browser scanner (43 total). All production Java sources compile against Android 35 and pinned dependencies. Existing metadata, engine, XHS, download-progress, save/repair, multi-region, gallery/queue, catalog, and JavaScript regressions passed.
- Android window attachment, manual verification/login, session retry, MediaStore and actual end-to-end three-site/Douyin downloads have not been tested on an Android device/emulator. Do not equate fixture tests or APK packaging with those missing device/network checks. The user's failing Douyin share link has not been provided.
