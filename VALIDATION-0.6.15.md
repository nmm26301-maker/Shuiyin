# 0.6.15 verification — 2026-10-25 (Asia/Shanghai)

- Added a reproducible JDK 17 + Node search test runner, compiling all production sources with a generated resource stub and real org.json before Android framework stubs. It verifies pinned engine dependencies, pins the JSON test jar checksum, clears stale bytecode, and uses a checked-in base64 fixture generated from a synthetic FFmpeg video. No ECJ or host FFmpeg is required to execute this gate.
- Local execution passed 9 JVM suites (254 assertions) and 3 actual collector JavaScript suites (45 assertions): 299 total. These include real local HTTP media probes and native yt-dlp ZIP transfer tests. A further 4 tests exercise the actual release shell script with a mock GitHub CLI: new prerelease/exact commit/checksum, same-commit rerun, different-commit refusal and authorization-failure refusal. bash syntax validation passed. Fixture and protocol tests do not establish live-site availability.
- The APK workflow now runs this gate before packaging. Test/tool changes trigger the workflow. Build has read-only repository access; a separate main-only publisher depends on successful build, downloads that exact workflow artifact, and creates a development prerelease with the APK and SHA-256 file. Another commit's release is never overwritten; API failures other than HTTP 404 do not trigger creation. CLI usage follows https://cli.github.com/manual/gh_release_create and GitHub token documentation at https://docs.github.com/en/actions/tutorials/authenticate-with-github_token .
- The prerelease download route is intended to avoid the independent-file saving failure seen in the prior round. Final cloud build, regression and publication statuses must be checked before reporting that a direct APK is available. Existing development signing is unchanged.
- No live Douyin success, all-three-provider availability or Android UI interaction is demonstrated. Those still require a reproducible public work link or device diagnostic. This release improves regression enforcement and installation-package delivery; it does not claim a new working download interface.
